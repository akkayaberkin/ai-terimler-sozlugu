# AI Terimler Sözlüğü 🇹🇷

## Format

Her terim için:
- **Türkçe karşılığı** (varsa yaygın kullanım)
- **Ne işe yarar** (1-2 cümle)
- **Detaylı açıklama** (3-5 cümle, teknik ama anlaşılır)
- **Kod/örnek** (varsa Python veya C# snippet)
- **İlişkili terimler**
